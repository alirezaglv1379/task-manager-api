# 📋 پروژه‌ی مدیریت تسک‌ها (Task Manager API)

## 🎯 هدف پروژه
طراحی و پیاده‌سازی یک RESTful API برای مدیریت تسک‌های روزمره کاربران. این پروژه شامل احراز هویت امن، مدیریت تسک‌ها، و فیلترهای پیشرفته است.

## 🛠️ تکنولوژی‌های استفاده‌شده
- **FastAPI**: فریم‌ورک اصلی برای ساخت API
- **SQLAlchemy**: ORM برای ارتباط با دیتابیس
- **SQLite**: دیتابیس سبک و قابل حمل
- **JWT / OAuth2**: احراز هویت و امنیت
- **Pydantic**: اعتبارسنجی و سریالایز کردن داده‌ها
- **Uvicorn**: سرور برای اجرای برنامه
- **bcrypt**: هش کردن رمز عبور

## ✨ قابلیت‌های کلیدی
- 🔐 احراز هویت امن با JWT
- 👤 ثبت‌نام و ورود کاربران
- 📝 عملیات CRUD کامل برای تسک‌ها
- 🔄 ویرایش کامل (PUT) و ویرایش جزئی (PATCH)
- 🎯 فیلتر کردن تسک‌ها بر اساس وضعیت انجام‌شده
- 🔒 مالکیت داده: هر کاربر فقط به تسک‌های خود دسترسی دارد
- 📚 مستندسازی خودکار با Swagger
