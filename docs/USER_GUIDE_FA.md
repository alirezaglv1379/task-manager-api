# راهنمای استفاده فارسی

## شروع کار

1. ابتدا بک‌اند و فرانت‌اند را طبق `SETUP.md` اجرا کنید.
2. در صفحه ورود، از بخش «ثبت‌نام کنید» یک حساب بسازید.
3. پس از ثبت‌نام، برنامه با همان حساب وارد می‌شود.

## مدیریت وظایف

- با «وظیفه جدید» یک عنوان و توضیح اختیاری ثبت کنید.
- برای علامت‌گذاری انجام‌شدن، مربع کنار وظیفه را انتخاب کنید.
- از دکمه ویرایش می‌توانید عنوان، توضیح و وضعیت را تغییر دهید.
- حذف وظیفه نیازمند تأیید شماست.
- فیلترهای «همه»، «در انتظار» و «انجام‌شده» فهرست را محدود می‌کنند.
- مرتب‌سازی بر اساس جدیدترین، قدیمی‌ترین و عنوان در API انجام می‌شود.
- صفحه‌بندی از سمت سرور است؛ هر صفحه حداکثر ۱۰۰ مورد می‌تواند داشته باشد و مقدار پیش‌فرض ۲۰ است.
- جست‌وجوی فعلی رابط کاربری فقط در صفحه دریافت‌شده انجام می‌شود.

## ورود و نشست

Access Token فقط در حافظه مرورگر نگهداری می‌شود. Refresh Token در کوکی HttpOnly قرار دارد و جاوااسکریپت به مقدار آن دسترسی ندارد. در صورت انقضای Access Token، فرانت‌اند برای تمدید نشست تلاش می‌کند. خروج از حساب، Refresh Session فعلی را باطل و کوکی را پاک می‌کند.

## نکات مهم

- نام کاربری باید ۳ تا ۳۰ نویسه باشد.
- رمز عبور حداقل ۸ نویسه و حداکثر ۷۲ بایت UTF-8 دارد؛ محدودیت ۷۲ بایت برای سازگاری با Bcrypt است.
- عنوان وظیفه ۱ تا ۲۰۰ نویسه و توضیحات حداکثر ۲۰۰۰ نویسه است.
- زمان ایجاد وظایف در دیتابیس UTC ذخیره می‌شود و در مرورگر با منطقه زمانی دستگاه نمایش داده می‌شود.
- فایل `.env` و دیتابیس واقعی را در GitHub عمومی منتشر نکنید.
